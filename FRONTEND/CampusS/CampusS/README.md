# CampusSpace – Smart Campus Resource Management & Booking System

## Overview
**CampusSpace** is a web‑based application for managing and booking campus resources. It provides two separate user interfaces:
- **Admin/Teacher** – for managing resources, approving bookings, etc.
- **Student** – for browsing and booking resources.

The current foundation includes a clean, modular folder layout, an Express.js server, static frontend serving, placeholder API routes, and a JSON‑file based storage service.

### Backend Details
- **Express** handles JSON API routes under `/api/*`.
- **Static files** (`frontend/`) are served automatically.
- A **file‑storage service** (to be added) will read/write JSON files under `backend/data/`.
- Centralised configuration lives in `backend/config/config.js`.

### Frontend Details
- Plain HTML5/CSS3 with vanilla JavaScript – no frameworks.
- `index.html` offers a welcome screen to choose the desired interface.
- Future admin and student pages will be built in `admin.html` and `student.html`.

## Setup Instructions
1. **Install Node.js** (includes `npm`).
   ```bash
   # Windows – download from https://nodejs.org/
   # Verify installation
   node -v
   npm -v
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start the server**
   ```bash
   npm start
   ```
   The server will listen on `http://localhost:3000` (or the `PORT` env var).
4. Open a browser and navigate to `http://localhost:3000` – you should see the welcome page.
